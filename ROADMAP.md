# Roadmap

Goal: the easiest way for online service providers (VAs, OBMs, social media managers, etc.)
to edit talking ("yapping") reels and turn one video into lots of content.
Everything should be swappable and quick to redo.

## Now: Version A, service providers making their own content
Delivered like a Claude Code product: buyers run the engine on their own computer inside their
own Claude Code (no hosting or AI costs for us). Get this right and tested on real reels before
building Version B.

Done
- Upload from phone, transcription with word timings, export a 1080×1920 MP4
- Tabs: Cut, Visuals, Sound, Finish
- Cut by the word, remove pauses, cut ums
- Hook (position, font, colour, duration) and captions (phrase/one word, bubble/coloured/serif key words)
- Post caption writer + "About your business" profile
- Light theme with brand purple
- Each reel has its own look; saved looks; "Make this my default"
- Trial reels: 3 versions (question, bold statement, POV) with different hook styles, auto-exported
- "Do it for me" upload: cut, captioned, styled, exported, post caption written
- Hook library by role, saved call-to-action keywords, "Not sure what to film?" idea starters
- Media library: GIFs, images and b-roll on any line, with Swap, placement, size, timing and Remove
- Editor rebuilt: Cut (numbered lines), Visuals (toolbar + line-by-line looks with Swap),
  Sound (music that ducks under the voice + sound effects per line, 10 starter sounds),
  Finish (export, trial reels, caption); play bar with a "Next" button on every tab
- Hook styles: headline, eyebrow + headline, headline + subhead (with previews)
- 42 bundled fonts grouped Clean / Serif / Script (incl. upright serifs), any font for captions or hook,
  plus upload-your-own fonts, sounds and music
- Starter looks (Editorial, Bold, Soft) and zoom jumps between lines
- Brand kit page: build a brand from a few questions or enter your own (palette, font trio,
  logo, voice, business); drives default look, color swatches and Claude's writing (brand-kit skill)
- Repurpose: carousel (4:5) and stories (9:16) from every reel, in the reel's style, editable,
  saved as images; Claude can write them (repurpose-reel skill)
- Claude Code layer: CLAUDE.md + skills (set me up, edit my reels, plain-words changes, update me),
  engine commands, inbox/outputs folders, editor updates live while Claude works

- Renamed The Cutroom; cleaner site design; reel folders (To edit / Ready to post / Posted)
- Tight editing: silences detected from the audio, retakes and repeats cut, Tighten button
- AI buttons use the creator's own Claude Code when there's no API key
- Visuals: Style (look gallery with previews) and Lines & media; 9 named looks; captions beside
  your head; karaoke captions; captions on/off; logo on reels; zoom jumps
- 22 starter sounds; slide designs (photo, framed, clean, bold) and photo backgrounds
- B-roll trial reels with the content in the caption; broll folder
- Brand kit built from an inspiration board (any Google Font)
- Cover picker; mark as posted; posting plan; repurpose-old-content and weekly-batch skills

Next (in rough order)
1. Test on a real Windows PC with Claude Code (Sarabeth is the first "buyer")
2. Graphic cards Claude can fill in: count-up number, stat card, checklist, quote
3. Client wins: testimonial to quote card, and client case study carousel
4. "Tell Claude what you want" for a line (three options to pick from)
5. Drag text anywhere on the preview
6. Cover a face (blur or sticker that follows a face)
7. Replace the synthesized starter sounds with a licensed sound pack

## Later: Version B, VAs editing reels for their clients (upgrade)
- Multiple brand kits, one per client (the brand kit is built so this can be added)
- A separate brand kit and business profile per client
- Switch between clients
- A share link the client can open to review and approve a reel
- Positioned as "offer reel editing as a paid service"
- Will need real accounts/logins and per-customer data before selling
